# Reporting

This repository ships no software, so there is nothing here to patch and this is
not a vulnerability policy. It is the route for asking that specific archived
content be taken down.

Use it if you are the owner of data captured inside a kit, a brand being
impersonated, or the owner of a host that was compromised to serve one.

Report privately. A public issue would republish the exact path you are asking
to have removed.

- [GitHub private reporting](https://github.com/0xDanielLopez/phishing_kits/security/advisories/new)
- info@phishunt.io

Include the `path` or the `sha256` from `index.csv`, what the content is, and
your relation to it. That is enough, and please do not attach the archive
itself.

Substantiated requests are removed from the tip of `master`. This is a personal
project and there is no SLA. Git history and the existing forks are outside my
control, so removal cannot be guaranteed to be complete. You can also report
this repository to GitHub directly under its Acceptable Use Policies.
